# 치지직 채팅 전용 창

## 키보드와 창 설정

- 채팅·주소창 등 입력란에 포커스가 없을 때 **↑/↓**는 볼륨을 5%씩 변경하고 **←/→**는 5초씩 탐색합니다. 현재 재생 가능한 구간 안에서만 이동합니다. 메인 플레이어와 PiP 모두 지원합니다.
- **F**는 영상과 채팅을 함께 표시하는 전체 화면, **F11 / Alt+Enter**는 영상만 표시하는 전체 화면입니다. 같은 키로 종료하거나 Esc로 돌아옵니다. **전체 화면** 버튼도 영상 전용입니다. 입력란에서 글자를 입력하거나 채팅을 쓰는 중에는 단축키가 입력을 가로채지 않습니다. 메뉴·크기 조절 경계선의 방향키 동작도 유지합니다.
- 재생 바에 마우스를 올리면 해당 지점의 재생 시간, 라이브 최신 지점에서 지난 시간, 현재 위치에서 앞뒤로 몇 초 이동하는지를 보여줍니다. 클릭·드래그로 탐색할 수 있으며, 녹화/리플레이로 늘어난 실제 탐색 범위를 반영합니다. 재생 바에 초점을 두고 Home/End로 보관 시작·최신 지점으로 이동할 수도 있습니다.
- 메인 창과 PiP 창의 크기·위치를 각각 저장해 다음 실행에 복원합니다. 메인 창의 최대화 상태도 기억합니다. 감상모드·전체 화면의 임시 크기는 일반 창 설정을 덮어쓰지 않습니다. 모니터 구성이 달라져 기존 위치가 화면 밖이라면 보이는 화면 안으로 보정합니다. 설정은 개인 프로필의 `window-state.json`에 저장되어 배포에서 제외됩니다.

## 녹화와 리플레이

독립 앱에서 영상을 재생한 뒤 **녹화 시작**을 누르세요. **녹화 종료**를 누르면 영상 조각을 하나의 `video.mp4`로 합칩니다. **저장 폴더 열기**로 결과를 확인할 수 있습니다. 파일은 앱 실행 파일 옆 `Recordings/Recording-...` 폴더에 저장하며 MP4 합치기에 성공하면 TS 조각과 `recording.m3u8`을 삭제해 `video.mp4`만 남깁니다. 최근 구간 저장에도 동일하게 적용합니다. 네트워크 오류나 합치기 실패 시에도 이미 저장한 녹화 폴더는 지우지 않습니다.

**리플레이 보관**은 1분·5분·10분·30분·1시간·2시간 중 선택하고 **리플레이 버퍼 시작**을 누릅니다. 시작 이후에 수신한 영상만 쌓입니다. **N분 뒤로** 또는 플레이어 탐색 막대로 과거 영상을 볼 수 있고 **LIVE**로 최신 위치로 복귀합니다. 아직 설정 시간만큼 쌓이지 않았다면 보관 시작 지점까지만 이동합니다. **최근 구간 저장**은 현재 재생 위치를 기준으로 이전 N분을 별도의 MP4로 저장합니다.

- 녹화/버퍼는 FFmpeg로 재인코딩 없이 영상 조각을 저장합니다. 별도로 FFmpeg 실행 파일이 필요합니다. 이 컴퓨터의 설치된 FFmpeg는 자동 인식하며, 다른 컴퓨터에서는 FFmpeg를 설치하거나 앱 폴더에 `tools/ffmpeg.exe`를 넣으세요. 현재 검증한 버전은 FFmpeg 8.1.1입니다. FFmpeg 바이너리는 기본 배포 파일에 포함하지 않습니다.
- 녹화·버퍼를 시작하면 수신한 로컬 HLS를 플레이어에서 재생합니다. 최초 조각을 준비하는 데 수 초가 걸리며 영상에 따라 더 걸릴 수 있습니다. 채팅과의 지연도 달라질 수 있습니다.
- 시작/종료와 구간 저장은 영상 조각 및 키프레임 단위입니다. 버튼을 누른 시점과 최종 영상의 경계에 조각 길이만큼 차이가 있을 수 있습니다. 프레임 단위 정밀 편집은 아닙니다.
- 녹화/버퍼가 켜져 있는 동안 채널·화질·원본 주소 변경은 먼저 녹화와 버퍼를 종료해야 합니다. 감상모드와 PiP는 이용할 수 있습니다.
- 리플레이는 현재 재생 위치 이전의 설정 시간과 안전 여유분을 남기고 지난 조각을 정리합니다. 되감거나 일시정지하면 해당 지점을 보존하면서 최신 영상도 수신하므로 디스크 사용량이 늘어날 수 있습니다. 화면에 실제 사용량을 표시합니다.
- 버퍼 종료 시 임시 `.buffer` 자료는 정리하지만, **녹화**나 **최근 구간 저장**으로 만든 폴더는 유지합니다. 녹화 중 앱을 닫으면 저장 후 종료할지 묻습니다.
- 리플레이 버퍼 종료와 버퍼 없는 녹화 종료 시에는 기존 영상을 재생하면서 라이브 연결을 먼저 준비합니다. 준비된 영상으로 전환한 뒤 FFmpeg 종료·파일 정리/합치기를 수행하므로 정리 대기 중에도 라이브 시청을 계속할 수 있습니다. 라이브 연결 준비에 실패하면 기존 버퍼를 유지하고 오류를 표시합니다.
- `Recordings`와 그 안의 녹화·리플레이 자료는 개인 사용 데이터이므로 배포용 ZIP에는 포함하지 않습니다.

## 독립 데스크톱 앱 (영상 + 공식 채팅 통합)

**`start-app.cmd`** 또는 **`dist/ChzzkViewer/ChzzkViewer.exe`**를 실행하세요. Chrome·Zen이나 별도 Node.js 설치 없이 실행됩니다. 방송 주소를 입력하고 **방송 열기**를 누르면 영상과 공식 채팅을 같은 창에서 사용할 수 있습니다.

- 오른쪽 채팅 입력란을 눌러 네이버에 직접 로그인하세요. 로그인 이후 공식 채팅에서 메시지를 입력하고 전송할 수 있습니다. 로그인 정보는 앱의 전용 Chromium 프로필에 저장되며 Chrome·Zen의 로그인과는 별개입니다.
- 채팅 ON/OFF, 채팅 새로고침, 별도 채팅 창을 지원합니다. 로그인 팝업도 앱 내에서 열립니다.
- 채팅 우측 상단 **네이버 로그인** 버튼으로 로그인 전용 창을 열 수 있습니다. 직접 로그인한 뒤 창을 닫으면 채팅을 새로고침합니다. 로그인 폼이 빈 팝업을 먼저 여는 동작도 지원합니다. 로그인 도중 차단된 이동과 연결 오류는 `profile/login-diagnostics.log`에 시각·호스트·오류 코드만 기록합니다. 아이디, 비밀번호, 쿠키, 주소의 경로 및 쿼리는 기록하지 않습니다. 캡챠 표시 여부와 로그인 허용 여부는 네이버가 결정합니다.
- 공식 로그인 호스트 `nid.naver.com`의 HTTP 이동 요청은 네트워크 전송 전에 HTTPS로 변경합니다. 다른 HTTP 호스트는 허용하지 않습니다. 진단 기록에 프로토콜도 표시합니다.
- 상단 로고·주소창은 스크롤해도 고정됩니다. 앱 시작 시에는 최고 화질을 기본 선택하며, 실행 중 바꾼 화질은 해당 실행 동안 재연결에도 유지됩니다.
- HLS/LLHLS 옆 `?`에 마우스를 올리거나 키보드로 초점을 두면 차이를 설명합니다. 영상은 사각형으로 전체 프레임을 표시하며, 영상·채팅 사이 경계선을 드래그해 너비를 조절할 수 있습니다. 경계선에 초점을 두고 좌우 방향키로도 조절할 수 있고, 더블 클릭 또는 Home으로 기본 너비를 복원합니다. 조절한 너비는 다음 실행에도 유지됩니다.
- 공식 사용자 상태 API로 로그인 여부를 확인해 **네이버 로그인 / 로그아웃** 버튼을 전환합니다. 로그아웃은 네이버 로그아웃을 요청하고 앱 전용 채팅 세션의 로그인 저장 데이터를 제거한 뒤 비로그인 상태를 다시 확인합니다. Chrome·Zen의 로그인 세션에는 접근하지 않습니다.
- 주소창과 방송 열기 버튼은 상단 왼쪽에 배치하고, 로그인 시 남는 공간에 **팔로우 LIVE** 목록을 표시합니다. 라이브 중인 채널을 누르면 방송 주소를 채우고 즉시 재생합니다. 목록은 1분마다 자동 갱신되며 새로고침 버튼으로 즉시 갱신할 수 있습니다. 많은 채널은 가로 스크롤로 확인합니다. 로그아웃 시 목록을 지우고 숨깁니다.
- 처음 사용하는 프로필의 주소창은 빈칸입니다. 주소창에서 정상 연결한 마지막 주소는 저장하여 다음 실행에 복원합니다. 데스크톱 앱은 로컬 서버 포트가 바뀌어도 유지되도록 앱 프로필의 `last-address.json`에도 저장합니다.
- 방송 제목 옆 **LIVE** 또는 **라이브로** 버튼을 누르면 현재 탐색 가능한 가장 최신 위치의 0.5초 전으로 이동하고 재생을 재개합니다. 서버에서 아직 제공하지 않은 영상까지 이동할 수는 없습니다.
- **감상모드**를 누르면 주소창·채팅·부가 UI를 숨기고 창 전체를 영상에 사용합니다. 독립 앱은 16:9 비율의 작은 플레이어 창으로 바뀌며, **감상모드 종료** 또는 Esc로 원래 창 크기와 레이아웃을 복원합니다. 영상 위로 마우스를 움직이면 종료 버튼이 보입니다.
- 영상에서 **우클릭 → PiP 모드**를 선택하면 영상만 별도의 작은 창으로 표시합니다. 독립 앱에서는 다른 창 위에 유지되는 전용 미니플레이어를 사용하며, 원래 영상은 일시정지하여 이중 재생을 막습니다. PiP 창의 닫기·돌아가기 또는 우클릭 메뉴의 **PiP 종료**로 원래 창에서 재생을 재개합니다. PiP는 영상이 재생 가능한 상태에서만 사용할 수 있습니다. WebUI에서는 브라우저가 지원하는 표준 PiP를 사용합니다.
- PiP에는 테두리·제목 표시줄·기본 재생 바가 표시되지 않습니다. 영상 영역을 드래그하면 이동하고, 가장자리·모서리를 드래그하면 16:9 비율로 크기가 바뀝니다. 마우스를 올리면 중앙의 **원래 창으로 돌아가기** 버튼이 나타납니다. Esc로도 복귀할 수 있습니다.
- 네트워크 응답 후에는 요청 취소 타이머를 해제하고, 영상 전송 중 시간 초과·PiP 전환에 따른 연결 종료는 스트림 오류로 처리합니다.
- 로그인 창이 로그인 서버에서 치지직 메인 또는 채팅 화면으로 돌아오면 자동으로 닫히고 현재 채널의 채팅을 다시 불러옵니다. 채팅 입력란에서 같은 화면으로 로그인한 경우에도 치지직 메인에 머무르지 않고 현재 채널의 채팅으로 복귀합니다. 로그인 처리 중간 페이지에서는 창을 닫지 않습니다.
- 화질 선택, m3u8 원본 주소 확인 및 편집 기능도 그대로 사용할 수 있습니다.
- 두 개의 독립된 웹 화면을 한 창에 배치합니다. 공식 채팅을 iframe에 넣거나 공식 페이지의 응답 헤더를 변경하지 않습니다.
- 앱을 닫으면 앱에 포함된 로컬 서버도 종료됩니다. 기존 WebUI 서버와는 독립적으로 동작합니다.
- 이동할 때는 EXE만 옮기지 말고 **`dist/ChzzkViewer` 폴더 전체**를 옮기세요. 로그인 프로필은 그 안의 `profile` 폴더에 저장됩니다.

개발 소스는 `desktop/main.cjs`와 `desktop/preload.cjs`입니다. `build-desktop.ps1`은 공식 Electron Windows x64 배포 파일을 받아 SHA-256 체크섬을 검증하고 실행 폴더를 만듭니다. Node 통합은 끄고, 컨텍스트 격리와 샌드박스를 사용합니다. 이 버전에서는 공식 채팅 표시와 비로그인 입력란까지 확인했습니다. 실제 로그인·메시지 전송은 사용자가 확인해야 합니다.

## 통합 WebUI (새 버전)

`start-webui.cmd`를 더블 클릭하면 `http://127.0.0.1:3131`이 열립니다. Node.js 22 이상이 필요하며, 이 컴퓨터에서는 Codex에 포함된 Node.js도 자동으로 찾습니다. 창의 방송 주소란에 치지직 라이브 주소를 입력하고 **방송 열기**를 누르세요.

- 공개 라이브 정보에서 HLS/LLHLS 재생 주소를 조회합니다. 일반 HLS를 우선 선택합니다.
- 재생 목록, 하위 재생 목록, 영상 조각, 키 주소를 로컬 서버가 중계합니다. 영상은 디스크에 저장하지 않습니다.
- 자동/수동 화질, 스트림 종류 선택, 다시 연결, 라이브 위치 이동, 전체 화면을 지원합니다.
- **화질** 메뉴에서 자동 또는 방송에서 제공하는 1080p·720p 등을 선택하면 해당 화질로 고정합니다. 현재 재생 화질과 프레임 수를 표시하며, 선택한 해상도를 현재 실행 중 다음 방송과 재연결에도 유지합니다. 앱을 새로 실행하면 최고 화질로 시작합니다. 선택한 해상도가 없는 방송은 자동으로 재생합니다. 단일 화질 m3u8은 다른 해상도를 제공하지 않으므로 방송 주소 또는 마스터 m3u8을 입력해야 화질을 바꿀 수 있습니다.
- 하단 **m3u8 직접 입력**을 펼치면 현재 재생 화질의 원본 주소가 표시됩니다. 화질 전환과 자동 화질 변경도 반영합니다. 주소를 수정하고 **수정 주소로 재생**을 누르면 해당 주소로 재생합니다. 입력 중에는 자동 갱신이 수정 내용을 덮어쓰지 않으며 **현재 주소 불러오기**로 최신 주소를 다시 가져올 수 있습니다. 방송 제목과 채팅 채널은 유지하고, **다시 연결**은 마지막으로 적용한 주소를 재시도합니다.
- 채팅 패널을 ON/OFF로 접을 수 있습니다. **별도 창**으로 공식 채팅에 참여합니다. 실제 확인 결과 공식 채팅의 `frame-ancestors` 정책이 네이버 도메인만 허용하여 localhost 내부 삽입은 거부됩니다. 이 버전은 영상과 채팅의 완전한 단일 창 통합을 지원하지 않습니다.
- 치지직 CDN의 HTTPS m3u8을 직접 입력할 수 있습니다. 현재 허용 도메인은 naver.com, pstatic.net, ntruss.com, akamaized.net, cloudfront.net 및 각 하위 도메인입니다.
- 네이버 비밀번호나 쿠키를 프로그램에 입력하지 않습니다. 로그인 필요 방송의 자동 추출은 지원하지 않습니다.
- 스트림이 만료되거나 끊기면 **다시 연결**로 방송 정보를 다시 조회합니다. 자동 주소 갱신은 아직 지원하지 않습니다.

서버는 이 컴퓨터의 루프백 주소에서만 접속할 수 있습니다. 브라우저를 닫아도 서버는 유지됩니다. 종료하려면 PowerShell에서 `./stop-webui.ps1`을 실행하세요. 개발 실행은 `node server.mjs`, 테스트는 `node --test`입니다.

HLS.js 1.6.15는 `public/vendor`에 포함되어 있으며 라이선스도 함께 제공합니다. 해당 파일이 없으면 실행기가 처음 실행할 때 내려받습니다. 방송 정보 조회 방식은 yt-dlp의 CHZZK 추출기(https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/chzzk.py)를 참고했습니다. 치지직의 비공식 API가 변경되면 수정이 필요합니다.

## 기존 채팅 전용 실행기

팟플레이어로 영상을 보면서 공식 치지직 채팅을 별도의 창에서 사용하는 Windows용 간단한 실행기입니다. Chrome 또는 Edge가 필요합니다. 추가 패키지는 설치하지 않습니다.

## 사용법

1. `start-chat.cmd`를 더블 클릭합니다.
2. 치지직 방송 주소(`https://chzzk.naver.com/live/채널ID`)를 붙여 넣습니다.
3. 열린 채팅 창에서 네이버 계정으로 로그인합니다. 이미 해당 브라우저에 로그인되어 있다면 기존 세션을 이용할 수 있습니다.
4. 팟플레이어 옆에 채팅 창을 배치합니다. 다른 채널을 열려면 실행기를 다시 실행합니다.

## 구현 범위

공식 `/live/채널ID/chat` 페이지를 브라우저 앱 모드로 여는 첫 버전입니다. 자체 채팅 클라이언트나 설치형 EXE는 아닙니다. 로그인과 메시지 처리는 공식 페이지에서 이루어지며 실행기는 계정 정보나 쿠키를 읽거나 저장하지 않습니다. 영상 재생과 m3u8 추출은 포함하지 않습니다.

방송과 채팅의 지연 차이는 자동으로 보정하지 않습니다. 공식 페이지의 주소나 동작이 바뀌면 수정이 필요할 수 있습니다. 로그인 및 실제 채팅 송수신은 사용자 계정으로 확인해야 합니다.
